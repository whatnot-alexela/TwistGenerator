# Код изменения (события) — 12 вариантов

| Код | Группа изменений | Тип изменения | Вид изменения |
|---|---|---|---|
| 1е | Изменения движения (Kinēsis) | Изменение Места | Естественное |
| 1и | Изменения движения (Kinēsis) | Изменение Места | Искусственное |
| 2е | Изменения движения (Kinēsis) | Изменение Качества | Естественное |
| 2и | Изменения движения (Kinēsis) | Изменение Качества | Искусственное |
| 3е | Изменения движения (Kinēsis) | Изменение Количества (Рост) | Естественное |
| 3и | Изменения движения (Kinēsis) | Изменение Количества (Рост) | Искусственное |
| 4е | Изменения движения (Kinēsis) | Изменение Количества (Убыль) | Естественное |
| 4и | Изменения движения (Kinēsis) | Изменение Количества (Убыль) | Искусственное |
| 5е | Изменения (Metabolē), не являющиеся движением | Возникновение | Естественное |
| 5и | Изменения (Metabolē), не являющиеся движением | Возникновение | Искусственное |
| 6е | Изменения (Metabolē), не являющиеся движением | Исчезновение | Естественное |
| 6и | Изменения (Metabolē), не являющиеся движением | Исчезновение | Искусственное |

**Правило.** Классификация изменения как естественного (е) или искусственного (и)
определяется характером ситуации в **Ожидании**, но не в Откровении.
